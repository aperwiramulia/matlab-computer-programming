5.1

Linear regression model

A simple linear regression model is written as \(y = a + bx\), where \(a\) is the intercept and \(b\) is the slope of the best-fit line. This form is used when the relationship between two variables is approximately linear.

\(\hat{y} = a + bx\)

\(e = y - \hat{y}\)

The first step is to organize the measured data in pairs of independent and dependent variables, then plot them as a scatter diagram. The scatter plot helps confirm whether the relationship is linear before conducting regression.

5.3

Least-squares method

The least-squares method determines the coefficients that minimize the sum of squared residuals. This gives the best-fit line closest to all data points in the sense of minimum total squared error.

\(e_i = y_i - \hat{y}_i\)

\(\mathrm{SSE} = \sum_{i=1}^{n}(y_i - (a + bx_i))^2\)

Minimize \(\sum (y - (a + bx))^2\)

5.4

Normal equations

The coefficients are obtained from the normal equations. For the model \(y = a + bx\), the system is:

\(na + (\sum x)b = \sum y\)

\((\sum x)a + (\sum x^2)b = \sum xy\)

n = length(P);
A = [n sum(P); sum(P) sum(P.^2)];
d = [sum(R); sum(P.*R)];
c = A\d;
a = c(1); b = c(2);

5.5

MATLAB implementation

x = [10 20 30 40 50];
y = [4 7 11 14 18];
X = [ones(length(x),1), x];
c = X\y;
a = c(1); b = c(2);
yhat = a + b*x;
scatter(x,y,80,'filled'); hold on;
plot(x,yhat,'-r','LineWidth',2); grid on;

This keeps the observed values as unconnected scatter points and the fitted line as a separate plotted regression curve, which is the clearest way to visualize the model fit.

5.6

Model quality measures

Several measures are used to evaluate the fit: residuals, standard error, RMSE, and the coefficient of determination \(R^2\). These indicators show whether the model explains the observed variation well and whether the residuals are small and randomly distributed.

\(e = y - \hat{y}\)

\(\mathrm{SSE} = \sum e^2\)

\(\mathrm{RMSE} = \sqrt{\frac{1}{n}\sum e^2}\)

\(R^2 = 1 - \frac{\mathrm{SSE}}{\mathrm{SST}}\)

e = y - yhat;
SSE = sum(e.^2);
RMSE = sqrt(mean(e.^2));
SST = sum((y - mean(y)).^2);
R2 = 1 - SSE/SST;

5.7

Interpolation and extrapolation

Interpolation uses the fitted model within the observed \(x\)-range. Extrapolation extends the relationship beyond the available data and is riskier because the model may not remain valid. It is important to check whether the engineering relationship remains physically reasonable.

5.8

Interpretation of slope and intercept

The slope \(b\) gives the average change in the response for each unit increase in the predictor, while the intercept \(a\) is the estimated response when \(x = 0\). In engineering applications, these values must be interpreted in relation to the actual problem, not only as algebraic coefficients.

5.9

Limitations of regression

A linear model is only valid if the relationship is approximately linear and the residuals do not show a strong systematic pattern. If the data are nonlinear, contain outliers, or are influenced by measurement errors, then a simple straight-line fit may be misleading.

5.10

Confidence and prediction intervals

After fitting the regression line, engineers should quantify the uncertainty of the estimate. Two common procedures are confidence intervals and prediction intervals.

  • Confidence interval for the mean response at a given \(x\)-value
  • Prediction interval for an individual future observation at a given \(x\)-value

\(\hat{y}_0 = a + bx_0\)

\(\hat{y}_0 \pm t_{\alpha/2, n-2} s \sqrt{\frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}}\)

\(\hat{y}_0 \pm t_{\alpha/2, n-2} s \sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}}\)

These intervals assume an appropriate linear model with independent, normally distributed errors and constant error variance. Five observations are insufficient to assess these assumptions confidently. A 95% confidence procedure has 95% long-run coverage; it does not assign 95% probability to a fixed parameter after the data have been observed.

The prediction interval is always wider than the confidence interval because it accounts for both parameter uncertainty and the random variability of individual observations. 

x0 = 35;
Sxx = sum((x - mean(x)).^2);
s = sqrt(SSE/(length(x)-2));
yp = a + b*x0;
SE_mean = s * sqrt(1/length(x) + (x0-mean(x))^2/Sxx);
SE_pred = s * sqrt(1 + 1/length(x) + (x0-mean(x))^2/Sxx);
tcrit = tinv(0.975, length(x)-2);
CI = [yp - tcrit*SE_mean, yp + tcrit*SE_mean];
PI = [yp - tcrit*SE_pred, yp + tcrit*SE_pred];
figure; plot(x,y,'o'); hold on; plot(x,yp,'r-');
plot([x0 x0],[CI(1) CI(2)],'k--');
plot([x0 x0],[PI(1) PI(2)],'b--'); grid on;
