P = [10;20;30;40;50];
R = [4;7;11;14;18];
figure; scatter(P,R,70,"b","filled"); grid on;
xlabel("Rainfall, P (mm)"); ylabel("Runoff depth, R (mm)");

Model

Linear relationship and least-squares principle

The model is expressed as R̂ = a + bP, where a is the intercept and b is the slope. Least-squares chooses the coefficients that minimize the total squared error between observed and predicted data.

Residual: e = R - R̂

Sum of squared errors: SSE = Σ(R - (a + bP))²

Normal equations: n a + (ΣP)b = ΣR

ΣP a + (ΣP²)b = ΣPR

Key result

For this data set, the fitted equation is approximately R = 0.30 + 0.35P.

This means that for each increase of 1 mm of rainfall, the model predicts roughly 0.35 mm more runoff within the calibration range.

MATLAB

Regression implementation in MATLAB

Manual normal equations

n = length(P);
A = [n sum(P); sum(P) sum(P.^2)];
d = [sum(R); sum(P.*R)];
c = A\d; a = c(1); b = c(2);

Direct least squares

X = [ones(length(P),1), P];
c = X\R; a = c(1); b = c(2);

Built-in fitting with polyfit

p = polyfit(P,R,1);
b = p(1); a = p(2);
R_pred = polyval(p,P);

User-defined function

function [a,b,R_pred] = myLinearFit(P,R)
    P = P(:); R = R(:);
    if numel(P) ~= numel(R) || numel(P) < 2
        error("Input vectors must have equal lengths >= 2.");
    end
    if any(~isfinite(P)) || any(~isfinite(R))
        error("Inputs must contain finite numbers.");
    end
    X = [ones(numel(P),1), P];
    c = X\R;
    a = c(1); b = c(2);
    R_pred = a + b*P;
end

Evaluation

Residual analysis, RMSE and R²

Model quality is judged by how far predictions deviate from the measured values. Residuals tell the story of bias, spread, and explanatory power.

Residual: e = R - R_pred

SSE: Σe²

RMSE: sqrt(mean(e²))

R²: 1 - SSE / SST

Interpretation

A high R² indicates a strong linear relationship, but it does not guarantee physical validity or good extrapolation outside the observed range. 

e = R - R_pred;
SSE = sum(e.^2);
RMSE = sqrt(mean(e.^2));
SST = sum((R - mean(R)).^2);
R2 = 1 - SSE/SST;

Chapter 5

Linear best fitting and regression analysis

5.1 Linear regression model

A simple linear regression model is written as y = a + bx, where a is the intercept and b is the slope of the best-fit line. This form is used when the relationship between two variables is approximately linear.

5.2 Data arrangement and plotting

The first step is to organize the measured data in pairs of independent and dependent variables, then plot them as a scatter diagram. The scatter plot helps confirm whether the relation is linear before conducting regression.

5.3 Least-squares method

The least-squares method determines the coefficients that minimize the sum of squared residuals. This gives the best-fit line closest to all data points in the sense of minimum total squared error.

Residual: e = y - ŷ

Least-squares objective: minimize Σ(y - (a + bx))²

5.4 Normal equations

The coefficients are obtained from the normal equations. For the model y = a + bx, the system is:

na + (Σx)b = Σy

(Σx)a + (Σx²)b = Σxy

5.5 MATLAB implementation

x = [10 20 30 40 50];
y = [4 7 11 14 18];
X = [ones(length(x),1), x];
c = X\y;
a = c(1); b = c(2);
yhat = a + b*x;
plot(x,y,'o',x,yhat,'-'); grid on;

5.6 Model quality measures

Several measures are used to evaluate the fit: residuals, standard error, RMSE, and coefficient of determination R². These indicators show whether the model explains the observed variation well and whether the residuals are small and randomly distributed. 

e = y - yhat;
SSE = sum(e.^2);
RMSE = sqrt(mean(e.^2));
SST = sum((y - mean(y)).^2);
R2 = 1 - SSE/SST;

5.7 Interpolation and extrapolation

Interpolation uses the fitted model within the observed x-range. Extrapolation extends the relationship beyond the available data and is riskier because the model may not remain valid. It is important to check whether the engineering relationship remains physically reasonable.

5.8 Interpretation of slope and intercept

The slope b gives the average change in the response for each unit increase in the predictor, while the intercept a is the estimated response when x = 0. In engineering applications, these values must be interpreted in relation to the actual problem, not only as algebraic coefficients.

5.9 Limitations of regression

A linear model is only valid if the relation is approximately linear and the residuals do not show a strong systematic pattern. If the data are nonlinear, contain outliers, or are influenced by measurement errors, then a simple straight-line fit may be misleading.

5.10 Confidence and prediction intervals

After fitting the regression line, the uncertainty of the estimate should be quantified. Two common intervals are used:

  • Confidence interval for the mean response at x = x₀
  • Prediction interval for an individual new observation at x = x₀

Predicted value: ŷ₀ = a + bx₀

Mean response interval: ŷ₀ ± tα/2,n-2 s√(1/n + (x₀ - x̄)²/Sₓₓ)

Prediction interval: ŷ₀ ± tα/2,n-2 s√(1 + 1/n + (x₀ - x̄)²/Sₓₓ)

The prediction interval is always wider than the confidence interval because it accounts for both parameter uncertainty and variation in individual observations. 

x0 = 35;
Sxx = sum((x - mean(x)).^2);
s = sqrt(SSE/(length(x)-2));
yp = a + b*x0;
SE_mean = s * sqrt(1/length(x) + (x0-mean(x))^2/Sxx);
SE_pred = s * sqrt(1 + 1/length(x) + (x0-mean(x))^2/Sxx);
tcrit = tinv(0.975, length(x)-2);
CI = [yp - tcrit*SE_mean, yp + tcrit*SE_mean];
PI = [yp - tcrit*SE_pred, yp + tcrit*SE_pred];
